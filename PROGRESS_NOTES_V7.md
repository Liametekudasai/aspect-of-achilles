# Progress Notes V7

## What changed in V7

- densified the repository with stronger documentation and testing guides
- upgraded Achilles pull from a one-tick push to a short sustained pull window
- improved tether state tracking with more runtime diagnostics
- improved recall constants and out-of-range damping behavior
- improved entity lifecycle checks in the tether helper entity
- rewrote the README to better match the real state of the project

## Intent of V7

V7 is meant to be the best handoff point before a real local NeoForge build. It is not pretending to be release-ready; it is trying to be materially useful when the first compile errors show up on a real machine.
